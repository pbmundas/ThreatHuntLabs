FIELD GUIDE / 01

From a lead to a
defensible hunt.

HUNTGRID turns a wide spreadsheet into an analyst-focused catalog. Use the library to discover hypotheses, confirm telemetry readiness, adapt detection logic, and structure an investigation.

01

Search broadly

The main search checks every field in every hypothesis. Search for a technique ID, process, event ID, cloud service, log source, IOC, platform, or phrase.

02

Narrow deliberately

Use tactic, severity, platform, and priority filters to create a manageable queue. Filters combine with the global keyword search.

03

Check readiness

Open a record and review prerequisites, required log sources, event IDs, and platform telemetry before launching the hunt.

04

Operationalize

Copy a platform query as a starting point, validate your field mappings, and use the investigation and confirmation criteria to drive triage.
